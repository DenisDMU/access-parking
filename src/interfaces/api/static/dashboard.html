Passage à la borne

La plaque est identifiée par Vehicles, qui renvoie un code : Access ne voit jamais la plaque, seulement ce code et la donnée anonymisée associée.
Pour une sortie juste après l'entrée, choisis « Dans 2 h 30 » : ça simule la durée de stationnement (sinon la 1re heure gratuite donne 0 €, donc aucun paiement).
En attente d'un véhicule
Saisis un code véhicule puis « Entrée » ou « Sortie ». La décision d'Access s'affiche ici.

Opérations disponibles

  • Entrée / sortie d'un véhicule par son code Vehicles : onglet Borne (POST /api/v1/access/requests).
  • Consulter une demande, l'historique d'un véhicule, ou vérifier un code : onglet Recherche.
  • Suivre les événements publiés aux autres services (RabbitMQ / webhooks) : onglet Journal.
  • Documentation interactive de l'API : /docs · santé : /health · métriques Prometheus : /metrics (clé API).
Renseigne ta clé API ci-dessus pour charger les événements.

Une recherche par code véhicule résout d'abord l'identifiant pseudonymisé auprès de Vehicles (/access/vehicles/{code}/known), puis liste son historique — Access ne stocke que l'identifiant pseudonymisé, donc il n'existe pas de recherche directe "par code" sur les demandes.
Choisis un type de recherche et une valeur, puis "Rechercher".
