Simulation

Passage à la borne

Vehicles identifie la plaque et renvoie un code : Access ne voit jamais la plaque, seulement ce code et la donnée anonymisée associée.

Heure de passage

Pour une sortie juste après l'entrée, choisis « +2 h 30 » : ça simule la durée de stationnement (sinon la 1re heure gratuite donne 0 €, donc aucun paiement).

Opérations disponibles

  • Entrée / sortie d'un véhicule par son code Vehicles : onglet Borne (POST /api/v1/access/requests).
  • Consulter une demande, l'historique d'un véhicule ou vérifier un code : onglet Recherche.
  • Suivre les événements publiés aux autres services (RabbitMQ / webhooks) : onglet Journal.
  • Documentation de l'API : /docs · santé : /health · métriques Prometheus : /metrics (clé API).

Événements publiés

Une recherche par code véhicule résout d'abord l'identifiant pseudonymisé auprès de Vehicles (/access/vehicles/{code}/known), puis liste son historique : Access ne stocke que l'identifiant pseudonymisé.
